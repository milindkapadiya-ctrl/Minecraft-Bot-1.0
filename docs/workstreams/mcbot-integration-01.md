## Reproduced blockers and required decision

1. **Composite ownership/action-history gap.** `runExclusive` is deliberately stationary and cannot enclose scan → walk → collect; nested actions are rejected. Individual actions release `active` before their result resolves. The exported collector has neither a whole-operation reservation nor a complete action epoch. The console's `sequence` flag only protects that console caller. In an offline probe using the existing CourseBot, an `action_result` logger scheduled an independent `runner.run({type:"inventory",timeoutMs:1000})` with `setImmediate` immediately after the first successful scanner exclusive action. It was accepted between scan completion and walking; the collector still succeeded with one step. Measured output: `{"independentAction":"ok","collection":"inventory_increase_observed","steps":1}`. This reproduces a safety gap, not a passing safety guarantee. Exact local commands: `node output/create-ownership-probe.cjs`, then `node --test --test-name-pattern='integration ownership blocker probe' dist/test/ownership-probe.mjs` (one diagnostic case, no skips). The generator copies the compiled existing course fixture and appends that hook; it creates no connection. No test asserting that this behavior is safe was added to the regression suite.
2. **Immediate single-use admission versus supplementary acquisition.** The inherited pit path consumes scan IDs once per collection call but uses their cells in multiple waypoint-planning calls, retains cells across separately owned lane/floor looks and combines later scans. It verifies endpoint position but has no operation-wide unexpected-action/move-away-and-return record between completed batches. The new private snapshots and sticky conflicts fix real local defects; they do not resolve this lifetime contract. Deleting supplementation would remove the working pit behavior without supplying an equivalent safe observation contract. Silently exempting those actions would violate the requested admission boundary. A coordinated acquisition/ownership decision is needed, within which the existing Perception scanner remains authoritative.
