## Minecraft 26.1 own-player air correction

Mineflayer 4.39.0 incorrectly writes bot oxygen/emits breath for **other entities'** air metadata. The protocol itself is unchanged: index1, named `int` / signed VarInt air supply; normal full player air300; displayed oxygen `round(raw/15)`. Foreign raw5610 reproduces374 through the actual installed plugin. The exact historical374 packet was not captured; a separate live comparison confirmed foreign raw5595→upstream373 contamination.

`src/minecraft/air-compat.ts` provides version-gated **ownAirView**: own entity only, validated integer/type/range, explicit unknown startup/reset, isolated own breath events. No dependency or unrelated metadata patch. Emergency and future holding/swimming composition must use this view and its `read`; never trust original Mineflayer oxygen/breath. Unknown is not zero/full air. Source/codec tests and read-only live verification passed. See `docs/air-compatibility.md`; do not rediscover this defect or broadly upgrade dependencies.
